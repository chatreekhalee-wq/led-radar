ติดตั้งปุ่ม “เก็บทรัพย์ LED”

กรอกค่าจาก Supabase แล้วลากปุ่มไปวางบนแถบบุ๊กมาร์กของ Chrome · ค่าเหล่านี้อยู่ในเครื่องคุณเท่านั้น หน้านี้ไม่ได้ส่งไปไหน

ลากปุ่มนี้ไปวางบนแถบบุ๊กมาร์ก (กด Ctrl+Shift+B ถ้าแถบไม่แสดง):

📥 เก็บทรัพย์ LED
  1. เปิดหน้าค้นหาทรัพย์ของกรมบังคับคดี ค้นตามจังหวัด/ประเภทตามปกติ
  2. เมื่อผลค้นหาขึ้น กดปุ่มนี้หนึ่งครั้งต่อหนึ่งหน้า (หน้ารายละเอียดทรัพย์ก็กดได้ ข้อมูลจะละเอียดกว่า)
  3. มุมขวาล่างขึ้น “เก็บแล้ว ✓” = เสร็จ · ถ้าขึ้นสีแดง ระบบจะดาวน์โหลดไฟล์ .json ไว้ให้ นำเข้าด้วย python -m worker.import_json

ปุ่มนี้อ่านเฉพาะหน้าที่คุณเปิดอยู่ตอนกด ไม่เปิดหน้าอื่นเองและไม่ทำงานเบื้องหลัง
