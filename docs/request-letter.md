# ร่างอีเมลขอข้อมูล — ส่งถึง itsupport@led.mail.go.th
(ศูนย์เทคโนโลยีสารสนเทศและการสื่อสาร กรมบังคับคดี)

**เรื่อง:** ขอใช้ข้อมูลประกาศขายทอดตลาดรายทรัพย์ในรูปแบบข้อมูลเปิด (CSV/API)

เรียน ผู้อำนวยการศูนย์เทคโนโลยีสารสนเทศและการสื่อสาร กรมบังคับคดี

กระผม [ชื่อ-นามสกุล] วิศวกรโยธา (ภาคีวิศวกร เลขทะเบียน [เลขที่]) กำลังพัฒนาเครื่องมือส่วนบุคคลเพื่อช่วยวิเคราะห์ทำเลและราคาทรัพย์ที่ประกาศขายทอดตลาด สำหรับใช้ประกอบการตัดสินใจเข้าร่วมประมูล

ปัจจุบันชุดข้อมูลบนระบบบัญชีข้อมูลของกรมฯ (opendata.led.go.th) เป็นข้อมูลสถิติรวมตามประเภททรัพย์ และเว็บไซต์ค้นหาทรัพย์ได้กำหนดไม่ให้ระบบอัตโนมัติเข้าถึง กระผมจึงขออนุญาตสอบถามว่ากรมฯ สามารถให้บริการข้อมูลประกาศขายทอดตลาดรายทรัพย์ในรูปแบบใดรูปแบบหนึ่งต่อไปนี้ได้หรือไม่

1. ไฟล์ CSV/Excel รายสัปดาห์หรือรายเดือน
2. API สำหรับผู้ใช้ที่ลงทะเบียน
3. การอนุญาตให้ดึงข้อมูลจากเว็บไซต์ค้นหาทรัพย์ในความถี่ที่กรมฯ กำหนด

ฟิลด์ที่ต้องการ: เลขคดี ลำดับที่ ประเภททรัพย์ เลขเอกสารสิทธิ์ ที่ตั้ง (ตำบล/อำเภอ/จังหวัด) เนื้อที่ ราคาประเมิน วันนัดขายและผลการขายแต่ละนัด และหมายเหตุ/เงื่อนไขการขาย

กระผมจะใช้ข้อมูลเพื่อการวิเคราะห์ส่วนบุคคลเท่านั้น ไม่นำไปจำหน่ายต่อ และพร้อมปฏิบัติตามเงื่อนไขการใช้ข้อมูลที่กรมฯ กำหนด
